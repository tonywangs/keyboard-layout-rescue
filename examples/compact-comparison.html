Model and limitations
    Views are paginated; browser Find searches only the mounted page. Use page controls or a zero-based code-point index to reach all text; use finding filters and pages to reach every diagnostic. Copy and downloads contain the complete text regardless of page or filter. Tabs and line endings are preserved in exports. Page boundaries preserve code points and CRLF pairs, but may split grapheme clusters. Columns count code points; only LF starts a new line. The visual display may conceal control characters, bidirectional text, or combining marks; consult JSON diagnostics and code-point offsets for exact values.
